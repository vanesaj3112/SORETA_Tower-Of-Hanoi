# Tower of Hanoi (Prolog)

## Live Website

https://vensonsoy.github.io/Tower_of_hanoi_deveyra/

## About the Project

An interactive Tower of Hanoi game. **Prolog** (`hanoi.pl`, running in the browser through Tau Prolog) computes the correct solution and validates every move, and **JavaScript** animates the disks.

## Features

- 3 to 8 disks
- AUTO SOLVE powered by Prolog
- Manual play (click a tower to pick up and place a disk)
- Pause, Resume, Reset, and Speed control
- Sound effects with an ON/OFF toggle
- Move counter, timer, and progress indicator
- Correct minimum number of moves: 2ⁿ − 1

## Files

- `hanoi.pl` - Prolog rules: recursive solver, move validation, minimum moves
- `index.html` - page structure
- `style.css` - styling
- `script.js` - game flow, animation, and sound

## How to Play

Open the Live Website link, choose the number of disks, then press **AUTO SOLVE** or play yourself by clicking the towers.
